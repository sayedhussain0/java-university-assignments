## Question (3)

Write a Java program (One class with a main method) to do the following:

1. Ask the user to enter (n) that represents the length of the array. The length of the array must be an even number otherwise print an appropriate message.
2. Declare two arrays of size n of type integer and prompt the user to enter the values of the arrays.
3. Swap the second half of the first array with the first half of the second array.
4. Print the elements of both arrays after the swap.

**Sample Input/output:**

```
Enter n: 5
The number of elements must be even
```

```
Enter n: 4
Enter 4 integers for the first array:  1 2 3 4
Enter 4 integers for the second array: 5 6 7 8

Array1 Elements after swapping:  1 2 5 6
Array2 Elements after swapping:  3 4 7 8
```
